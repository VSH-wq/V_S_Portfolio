## Deploy with GitHub Pages

1. Create a GitHub repository named `V_S_Portfolio`.
2. Upload `index.html` and `README.md` to the repository root.
3. Commit to `main`.
4. Open **Settings > Pages**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`.
5. Wait for the Pages build, then open the site URL.

No build step or backend required.
